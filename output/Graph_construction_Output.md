Graph construction output gives these files  they are :
Files 
1.hop_matrix: Matrix showing the shortest path lengths bewteen the nodes(protein pairs) 

2.adj_matrix: It represnts the edges between the nodes 

3.intimacy_matrix: Likely a weighted adjacency or similarity matrix based on shared features or embeddings

4.max_wl_code: Highest Weisfeiler-Lehman code used in graph isomorphism testing or node coloring

5.node_mapping: Maps protein pairs (or raw proteins) to internal node indices in the graph

6.protein_features: Vectorized representations or embeddings of proteins or protein pairs

7.degree_matrix: Diagonal matrix showing degree (number of edges) of each node

8.wl_codes: WL codes assigned to nodes — used for distinguishing structural roles in graph
